# 遇到的问题记录

## 1. tts读多音字不准
解决方式：1. 代码里调用tts前硬编码转换，如“换行符”-> "换杭符“

## 2. 脚本需要人工修改较多
解决方式： 调用大模型生成 
a. 免费智谱API调用----不太智能，会生成较多内容，需要手动调整较多
b. 直接提取PDF格式ppt。需要调整格式较多，手动修改，效率低
c. 上传ppt到chatgpt，使用5.2的版本生成脚本。（有些好使，有时候不好使）

### 提示词：
请为上传的PPT 幻灯片内容生成一段讲解脚本。要求如下： 
1. 第一页开场白为：大家好！今天我们开始来学习x.x(如3.2，或者大章节4)章节：XXXX。然后读出ppt中的其他内容。 
2. 除第一页外的其他页直接读内容。需要跳过大标题内容。 所以顶栏不适合阅读的标题都需要从生成的脚本中排除。
3. 脚本内容要适合使用大模型tts生成讲解音频。若ppt中的内容不适合大模型tts读音频，可适当改写。
4. 若整个ppt的内容音频总时长少于5分钟，则可对某些页面内容适当发挥，增加一些讲解内容。 
5. 最后一张如果是“感谢观看”，可适当扩写为一句话内容。 
6. 输出为jsonl文件，每页ppt的脚本占用一行。每行内容为{“page”:1, “script”:”xxxxx”}
